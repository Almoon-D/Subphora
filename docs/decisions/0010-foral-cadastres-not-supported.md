# 0010 — Foral cadastres: "not supported yet"

- Date: 2026-11-24 · Status: accepted · MASTER_PLAN §3
- Context: Álava, Gipuzkoa, Bizkaia and Navarra keep their own cadastres outside the
  national Catastro; the owner's estates are in Andalusia.
- Decision: a reference or location in those territories returns a clear "this territory's
  cadastre is not supported yet" message. The national potential map still covers them;
  only cadastral lookup is missing.
- Rejected: integrating four foral services now (no current user benefit).
